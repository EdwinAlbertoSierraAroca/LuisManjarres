# Solar Platform

Plataforma web moderna para empresas de energía solar, enfocada en una versión V1 con dashboard administrativo, landing page pública, gestión de clientes, cotizaciones y personalización de marca.

## Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS

## Scripts

```bash
npm install
npm run dev
```

## Objetivos de la V1

- Dashboard principal
- Empresa
- Servicios
- Proyectos
- Clientes
- Cotizaciones
- Brand Studio

## Desarrollo

La aplicación está pensada como una plataforma SaaS con estética premium solar, visualización de métricas y flujo de lead generation.
